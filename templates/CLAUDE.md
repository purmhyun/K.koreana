# 이 폴더의 작업 규칙

Claude는 이 폴더에서 일을 시작할 때마다 이 파일을 먼저 읽고 따른다.

## 시작할 때
1. `작업일지.md`의 맨 위 기록을 읽고, "다음 할 일"부터 이어서 진행한다.
2. 무엇을 해야 할지 애매하면 추측하지 말고 사용자에게 먼저 묻는다.

## 작업 중
- 결과물은 `결과물\` 폴더에 저장하고, 파일 이름에 날짜를 붙인다 (예: `보고서_2026-10-05.docx`).
- 기존 파일을 지우거나 덮어쓰기 전에는 사용자에게 먼저 확인한다.
- `_maintain\` 폴더는 작업 유지용 스크립트이므로 사용자가 요청할 때만 건드린다.

## 끝낼 때 (또는 중간에 멈출 때)
`작업일지.md` 맨 위(제목 바로 아래)에 아래 형식으로 기록을 추가한다.

    ## YYYY-MM-DD
    - 한 일:
    - 다음 할 일:
    - 메모 (막힌 점, 정한 것):
